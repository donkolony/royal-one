# Royal Square brand assets

The logo and mark are extracted directly from page 1 of `frontend/doc/resources/Royal Sqaure Financial Brief.pdf`. The artwork has not been redrawn or recoloured.

The source PDF contains a scanned JPEG, not vector artwork or specified brand colour codes. Dominant coloured pixels sampled from the original embedded logo image are:

- Blue: RGB 0, 46, 108 (`#002E6C`)
- Burgundy-red: RGB 175, 34, 76 (`#AF224C`)

These source-sampled values are the UI's primary brand tokens. Subtle transparent versions are used for surfaces; neutral greys and white are used for readability. These are faithful sampled values, not a claim of official Pantone or original design-file specifications.
